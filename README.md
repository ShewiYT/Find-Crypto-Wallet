## About

**Find Crypto Wallet** is a desktop utility designed to help users search for lost or forgotten cryptocurrency wallets, as well as detect unactivated CryptoBot checks. The project is actively maintained and regularly updated with new features and improvements.

---

## Features

- 🔍 Search for forgotten crypto wallets
- 🎁 Detection of unactivated CryptoBot checks
- 💾 Automatic saving of seed phrases and wallets with balance
- 📝 Telegram bot logging (token + chat ID)
- ⚙️ Custom output folder selection
- 🚀 Lightweight and easy to run — no installation required

---

## Installation & Usage

1. **Download** the archive from the [Releases](../../releases) section.
2. **Extract** it to any folder of your choice.
3. **Run** the executable file.
4. Fill in the following fields:
   - Telegram **Bot Token**
   - Telegram **Chat ID** (for logs)
5. Select the **folder** where found seed phrases and wallets with balance will be saved.
6. Start the search.
